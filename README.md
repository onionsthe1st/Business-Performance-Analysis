# Business Performance Analysis

## Project Overview

This project focuses on analyzing business performance using data analytics to uncover trends, evaluate key performance indicators (KPIs), and generate actionable insights that support informed business decisions.

The analysis explores different aspects of business operations, including revenue, profit, orders, customers, products, and regional performance across multiple currencies.

The project combines Python for data exploration and preprocessing with Power BI for data modeling, analytical calculations, and interactive dashboard development.

## Objectives

- Evaluate overall business performance through key performance indicators.
- Analyze revenue and profit trends across different regions and currencies.
- Understand customer purchasing patterns and order distribution.
- Identify top-performing and underperforming products.
- Examine product and order performance to uncover business opportunities.
- Present findings through interactive and informative dashboards.

## Project Workflow

### 1. Data Exploration and Preparation (Python)
- Inspected the dataset structure and data types.
- Explored business metrics and distributions.
- Performed data cleaning and preprocessing.
- Prepared the data for further analysis and visualization.

### 2. Data Modeling (Power BI)
- Imported the prepared datasets into Power BI.
- Established relationships between relevant tables.
- Designed a relational data model to support cross-table analysis.
- Created measures for business performance indicators using DAX.
